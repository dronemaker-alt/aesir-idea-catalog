# Æsir Idea Catalog

A searchable engineering inspiration and technology-mining catalog for Æsir Autonomous Systems.

The purpose is not to collect pretty pictures. Each entry records **why the idea was saved**, the engineering principle worth extracting, and where it may apply.

## Workflow
`RAW → INVESTIGATE → PROTOTYPE → INCORPORATED` (or `REJECTED`)

## Search dimensions
- Project: Cali-Eye, UAV, UGV, USV/ROV, NOMAD, lab, outreach/recycling
- Technology: motion-control, power, sensing, manipulation, structures, autonomy, comms, manufacturing
- Problem: serviceability, deployment, inspection, battery monitoring, recovery, recycling, etc.

## Catalog
See [catalog/index.md](catalog/index.md).

## Adding an idea
Copy [templates/idea-card.md](templates/idea-card.md), assign the next ID, and capture the **Why saved** field even if everything else is incomplete.
