# IDEA-022 — SwellPro SD4 Amphibious / Environmental UAV Architecture Reference

**Status:** INVESTIGATE  
**Captured:** 2026-09-24

## Observation

The SwellPro SD4 provides a useful commercial reference for an amphibious/environmentally protected multirotor architecture. The useful pattern is not a direct clone: a large sealed central body can combine avionics protection, flotation, landing/recovery functions, and payload accommodation while leaving propulsion modules comparatively exposed and serviceable.

## ÆSIR relevance

Potential application areas include Jotun and Sleipnir environmental variants, NOMAD field operations, sealed avionics modules, recovery systems, and lessons transferable to the Randy USV. A future ÆSIR implementation could investigate a positively buoyant sealed equipment pod, sealed connectors, sacrificial/conformal bumpers, and replaceable propulsion modules.

This is a reference only and does **not** change the frozen ÆSIR modular U-channel-spine airframe baseline.
